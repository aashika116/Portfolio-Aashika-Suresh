# Aashika Suresh Portfolio

This is a lightweight static portfolio website.

## Requirements
- Python 3 installed
- A modern web browser
- Git (if cloning the repository)

No external Python packages or pip install commands are required.

## Running locally
1. Clone the repository
```bash 
[git clone https://github.com/aashika116/Portfolio-Aashika-Suresh.git
```  
```bash 
cd Portfolio-Aashika-Suresh
```

2. Start the portfolio
Make the startup script executable:  
```bash 
chmod +x start.sh
```  

Then run:  
```bash
./start.sh
```  

The portfolio will be available at:
http://localhost:8000/

### Alternative: Run Without the Startup Script
If you don't want to use start.sh, you can start the built-in Python web server directly:
```bash
python3 -m http.server 8000
```  

Then open:
http://localhost:8000/
